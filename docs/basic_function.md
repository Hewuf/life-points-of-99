# 背景
本项目目的用里程碑的方式记录人的一生。将人的一生（99岁）抽象成页面中的 99 个点，以图的形式直观的看到当前的人生的进度，让人可以珍惜自己的时间。引发人关于人生和时间的思考，让人思考如何更好/更有意义的过完这一生。

## 我的初衷/我的感受
我做这个的初衷是突然发现，如果将自己的一生比作里程碑，我也就只能有99个里程碑。就觉得自己的一生很短暂，不应该浪费在无聊/没有意义的事情上。如果要在每年的“里程碑”上刻上自己一年发生的事情/总结，我希望这一年的时间里我过的是有意义的，我是有在认真生活的，而不是浪费时间的活着。这就是我做人生99点的初衷，希望也能引起其他人关于珍惜时间、人生意义的思考。

# 基本功能

## 主页面
1. 里程碑功能。页面上有99个点，每个点代表一年，展示是哪一年、多少岁。hover上去的时候会展示当年的总结（一句话，50字以内）
2. 对于本年（如今年是2026，本年就是2026年）的点会有正在进行的动态效果。 - to design
3. 对于未来年份缩小展示。这部分需要展示，因为可以直观看到还剩多少点。但是为了节省页面空间所以缩小展示，点之间的间距相比已经发生过的会较小且间距更近。点的颜色也会有比较暗淡，表示还未发生。
4. 对于过去年份，需要正常展示，即大小正常、间距正常、有色彩的点。
5. 点击今年及过去的点时可以跳转到详情页面。具体内容查看下面详情页面部分。


## 详情页面
1. 详情页面主要负责展示内容如下
    - 标题。当年的一句总结，对应主页面中提到的50字总结
    - 详细描述。不限字数
    - 这一年的关键词 / 事件。每条一句话，最多 8 条
    - 图片。最多12张。
2. 编辑按钮，通过点击编辑按钮可以修改当前详情内容。


## 登陆与权限
1. 目前用户只有我自己，所以只有我才有编辑权限。
2. 其他所有人打开该web后都只能查看我的人生，不允许修改。
3. 后续会逐渐支持其他人注册和登录自己的账号，编辑自己的“人生”

## 其他功能
1. 主题色。需支持明暗两个主题。


## 展望功能
1. 分享功能。有其他人加入后，可能会支持查看其他人的人生的功能。


# 设计相关
## 风格
1. 整体风格要简洁、有设计感。
2. 由于是人生里程碑的感觉，所以色调要有希望/梦幻感？（没想好。 - to design
3. 对于正在进行中的当年的交互，要有呼吸感。交互要有萤火虫的那种感觉。
